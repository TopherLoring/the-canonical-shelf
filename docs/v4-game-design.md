# v4 understanding-check design

## Shared shell

Every check opens in a dedicated board with:

- lesson/module context eyebrow;
- clear task title and one-sentence instruction;
- progress indicator;
- high-contrast interactive board;
- progressive hint control;
- explanatory feedback region;
- retry without penalty;
- visible return-to-lesson path.

The board is intentionally visually distinct from lesson prose so it feels like a learning activity rather than a web form.

## Pattern selection

| Cognitive task | v4 board |
|---|---|
| Put events/books/ideas in order | sequence-path / timeline-sort |
| Connect terms and meanings | match-board |
| Distinguish evidence strength | evidence-lab |
| Restore speaker/audience/setting | context-lens |
| Build reasoning | argument-map |
| Compare traditions/texts | compare-board |
| Transfer into life situation | scenario |
| Recall meaningful wording | verse-rebuild |
| Infer a book from evidence | book-detective |
| Trace a theme across canon | theme-trace |
| Synthesize multiple skills | capstone |

## Feedback tone

Wrong feedback should identify the missed distinction. It should not say only “wrong,” “try again,” or “not quite.” The learner should leave a failed attempt knowing what evidence to re-check.

Correct feedback explains *why* the construction is supported. Completion never claims that one exercise certifies comprehensive mastery of theology or faith.
